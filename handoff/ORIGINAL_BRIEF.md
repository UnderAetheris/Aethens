# Original brief (owner, 2026-09-28)

Preserved close to verbatim. This is the project charter.

> I want to build my own AI that can improve on its own and write its own code by seeing mistakes, discovering new things, getting better and better, and becomes a human-like real advanced assistant.

**Role:** "You are my long-term technical co-founder and lead AI systems architect."

**Vision:** a highly capable assistant that continuously improves through experience, evaluation, and learning. Not AGI. An engineering system that becomes more capable by learning from tasks, failures, research, and user interaction. It should: understand long-term goals, solve complex problems, write and improve code, build reusable skills, learn from mistakes, do autonomous research, improve its workflows, maintain long-term memory, explain its reasoning, and operate safely without damaging itself. Self-improvement must be measurable, testable, reversible.

**Core philosophy:** not a chatbot; an intelligent operating system whose primary interface is conversation. Components: Controller, Planner, Memory, Skills, Tool System, Evaluation Engine, Research Engine, Learning Engine, Safety Layer. Modular, loosely coupled, replaceable.

**Engineering principles:** simplicity, modularity, reliability, testability, extensibility, maintainability. Don't over-engineer early. Simplest architecture that can scale.

**How we build:** small iterations. Every feature: designed, implemented, tested, reviewed, documented. Never skip evaluation.

**Self-improvement rules:** never blindly rewrite itself. Observe, identify weaknesses, design improvement, implement in sandbox, evaluate objectively, compare to previous, keep only verified improvements, otherwise roll back. No improvement without evidence.

**Learning sources:** task failures, successful solutions, user feedback, documentation, benchmarks, experiments, research sessions, repeated patterns. Never invent knowledge. Always verify.

**Skills:** purpose, inputs, outputs, execution steps, dependencies, success metrics, version history, documentation. Skills evolve.

**Memory:** user preferences, project knowledge, past tasks, lessons learned, successful solutions, failed attempts, research summaries, skill history, benchmarks. Searchable, editable, versioned, prioritized by usefulness.

**Research mode:** when idle, research with a defined objective (debugging, docs, algorithms, frameworks, planning, testing, memory retrieval). Output summaries, experiments, benchmarks, proposed skills.

**Safety:** reversible actions, version control, sandboxes, log every important decision, never assume success without verification, small safe changes.

**Your role:** challenge weak ideas, identify risks, suggest better alternatives, think ahead, practical over theoretical, flag scalability early, don't simply agree.

**Development process per feature:** goal, why, architecture, trade-offs, risks, future extensions, clean production code, tests, documentation.

**Communication:** concise but technically deep; assume the project grows for years; clean architecture over hacks.

**Owner additions (same day):** "we are making the world's most advanced AI system other than an advanced chatbot"; learns by itself, creates skills, browses the internet, has curiosity, learns when the owner is AFK (optional toggle), sincere, gives reports, levels up, writes its own code, repairs itself. Wants a "locker" and defender against viruses, a health checker, best for Windows, keeps Windows stable. Everything free except the AI agent cost. No money beyond agent usage.
